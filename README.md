# App Store Reviews NLP Analysis

A Natural Language Processing project exploring App Store reviews and using machine learning to classify user sentiment.

## Overview

The project demonstrates a simple end-to-end NLP workflow:

- Load and explore App Store review data
- Filter English-language reviews
- Clean and preprocess text
- Transform text into features
- Train a sentiment classification model
- Evaluate predictions using accuracy and a confusion matrix

## Dataset

The project uses an **App Store Reviews dataset from Kaggle**, provided in JSON format.

## Tools

- Python
- Pandas
- Scikit-learn
- NLP preprocessing
- Matplotlib
- Jupyter Notebook

## Workflow

```text
JSON Data → Data Cleaning → NLP Preprocessing → Feature Extraction → Model Training → Evaluation
```

## Goal

The goal is to show how unstructured customer reviews can be transformed into structured insights using NLP and machine learning.
